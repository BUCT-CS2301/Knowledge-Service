## 二、根因分析

### P-22 收藏不入后台

- 搜索/分类链路文物主键为 Neo4j **`objectId`（UUID）**。
- 原收藏接口 `/search/searchById/collect` 仅接受 MySQL **数字 `rid`**。
- 详情页 `antiqueDetail.vue` 对非数字 rid 直接拦截：「该文物暂不支持收藏」。
- `collect` 表仅有 `user_id`、`user_collect_id`，无法存 UUID。

### P-17 ~ P-21

见本目前半部分及《服务器API接口说明》§5 新旧文档对比。

## 五、验证方式（已通过）

```bash
# 1) 分类搜索
curl -X POST http://127.0.0.1/search/classification \
  -H 'Content-Type: application/json' -d '{"c":"dynasty","v_1":"唐"}'
# → state:200

# 2) 收藏 Neo4j 文物
curl -X POST http://127.0.0.1/search/searchById/collect \
  -H 'Content-Type: application/json' \
  -d '{"uid":"1013","objectId":"f03910bd-0e85-4d88-bf21-c06c41fc7a13","relicName":"服装碎片"}'
# → state:200

# 3) 个人中心收藏列表
curl -X POST http://127.0.0.1/user_admin/collect \
  -H 'Content-Type: application/json' -d '{"id":"1013"}'
# → data 含 relicObjectId、relicname

# 4) 详情 if_collect
curl -X POST http://127.0.0.1/search/detailByObjectId \
  -H 'Content-Type: application/json' \
  -d '{"objectId":"f03910bd-...","uid":"1013"}'
# → if_collect: 1

# 5) 登录 / 用户详情
curl -X POST http://127.0.0.1/users/login \
  -d '{"username":"1001","password":"123456"}' -H 'Content-Type: application/json'
curl -X POST http://127.0.0.1/users/get_detail \
  -d '{"id":"1013"}' -H 'Content-Type: application/json'
```

**浏览器：**

1. 登录 → 分类浏览 → 唐 → 进入文物详情 → 点「收藏文物」  
2. 个人中心 → 我的收藏 → 应出现刚收藏的文物名称  
3. 刷新详情页 → 按钮显示「已收藏」
