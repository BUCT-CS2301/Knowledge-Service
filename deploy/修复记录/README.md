# 修复记录总目录

本目录用于跟踪海外文物知识服务系统每次部署、联调与问题修复的变更记录。

## 使用说明

- 每次集中修改后，在本目录新增一篇以日期命名的记录，例如：`5.28修改记录.md`
- 在本文件「记录索引」中补充一行，便于回溯
- 单篇记录建议包含：问题列表、修改文件、验证方式、待办事项
- 长期架构与部署说明仍见上级目录：[部署问题与解决方案备案.md](../部署问题与解决方案备案.md)

## 目录结构

```
deploy/
├── 修复记录/                 ← 本目录（按日期累积修改记录）
│   ├── README.md             ← 总索引（本文件）
│   ├── 5.28修改记录.md
│   └── 5.30修改记录.md
├── monitor.sh                ← 运维健康巡检脚本
├── monitor.timer             ← systemd 定时器（每 5 分钟）
├── monitor.service           ← systemd 巡检单元
├── logs/                     ← 巡检日志输出目录（ops-monitor.log，git 忽略）
├── 部署问题与解决方案备案.md  ← 长期问题库
├── SERVER-DEPLOY.md
├── database/
└── nginx-knowledge-service.example.conf
```

## 新增记录模板

复制以下文件名与结构即可：

```markdown
# M.D 修改记录

> 记录时间：YYYY-MM-DD
> 环境：

## 一、问题总览
## 二、修改文件清单
## 三、验证方式
## 四、待办事项
```
