## 1. 系统概述

欢迎使用**海外文物知识服务子系统**！本系统基于知识图谱技术，为用户提供海外流失文物的数据浏览、查询、可视化与个性化服务。系统界面设计参考了克利夫兰艺术博物馆、大英博物馆等国际一流博物馆网站的设计风格。

## 2. 数据浏览

### 2.1 多维筛选与排序

**筛选功能：**
1. 点击页面侧边栏或顶部的「筛选」按钮
2. 选择筛选维度：
   - **文物类型**：瓷器、青铜器、书画等
   - **年代**：按朝代或时间范围筛选
   - **所属博物馆**：大英博物馆、大都会博物馆等
   - **材质**：陶瓷、青铜、玉石、纸本等

**排序功能：**
1. 点击「排序」下拉菜单
2. 选择排序方式

### 2.2 文物详情页

**访问方式：**
- 在浏览列表中点击任意文物卡片或条目

**详情页包含内容：**

| 板块 | 内容 | 功能 |
|------|------|------|
| 文物图片 | 高清文物图片展示 | 支持缩放、全屏查看 |
| 基本信息 | 名称、年代、类型、材质 | 快速了解文物概况 |
| 馆藏信息 | 收藏博物馆、馆藏编号 | 溯源文物来源 |
| 尺寸信息 | 高度、宽度、重量等 | 了解文物规格 |

**图片操作：**
- **缩放**：使用鼠标滚轮或点击缩放按钮
- **全屏**：点击图片右下角全屏图标
- **关闭全屏**：按 ESC 键或点击关闭按钮


## 3. 数据查询

### 3.1 简单查询

**操作步骤：**
1. 在首页或搜索页面的搜索框中输入关键词
2. 支持搜索的内容：
   - 文物名称（如"青铜鼎"）
   - 博物馆名称（如"大英博物馆"）
   - 年代（如"宋代"）
   - 材质（如"陶瓷"）

3. 按下回车键或点击搜索按钮

**搜索结果页功能：**
- **分页导航**：支持翻页查看更多结果
- **二次筛选**：在结果页可进一步筛选

### 3.2 高级查询

**操作步骤：**
1. 点击搜索框旁的「高级搜索」按钮
2. 在高级搜索面板中填写筛选条件：
   - **文物类型**：多选
   - **年代范围**：起始年代 - 结束年代
   - **材质**：多选
   - **收藏地**：按国家/地区筛选
   - **博物馆**：具体博物馆选择

3. 点击「搜索」按钮执行查询


### 3.3 查询结果导出

**操作步骤：**
1. 执行查询后，在结果页找到「导出」按钮
2. 选择导出格式：
   - **CSV**：适合电子表格软件打开
   - **JSON**：适合程序处理或数据交换
3. 点击确认，浏览器自动下载文件

**导出内容包含：**
- 文物名称、objectId
- 年代、类型、材质
- 收藏博物馆
- 图片链接
- 文物描述

## 4. 数据可视化

### 4.1 知识图谱关系图

**访问方式：** 点击导航栏「知识图谱」选项

**功能特点：**

| 交互方式 | 说明 |
|----------|------|
| 节点点击 | 展开/收起关联实体 |
| 悬停显示 | 显示实体属性信息 |
| 缩放 | 鼠标滚轮缩放视图 |
| 拖拽 | 自由移动画布 |

**图例说明：**
- **文物节点**（紫色）：代表具体文物
- **博物馆节点**（蓝色）：代表收藏机构
- **朝代节点**（绿色）：代表历史时期
- **材质节点**（橙色）：代表制作材料
- **关系连线**：展示实体间的关联关系

### 4.2 文物时间轴

**访问方式：** 点击导航栏「时间轴」选项

**功能特点：**

| 功能 | 说明 |
|------|------|
| 朝代筛选 | 点击朝代标签筛选 |
| 时间范围选择 | 自定义时间段筛选 |
| 节点跳转 | 点击时间节点查看对应文物 |

**时间轴视图：**
- 横向时间轴展示各历史时期
- 每个朝代节点显示文物数量
- 点击节点展开该时期文物列表

### 4.3 文物地理分布图

**访问方式：** 点击导航栏「地理分布」选项

**功能特点：**

| 交互方式 | 说明 |
|----------|------|
| 地图缩放 | 鼠标滚轮缩放 |
| 标注点击 | 查看博物馆详情 |
| 国家筛选 | 按国家筛选博物馆 |

**地图标注信息：**
- 博物馆位置标记
- 馆藏文物数量
- 点击查看博物馆详情页

### 4.4 统计分析看板

**访问方式：** 点击导航栏「数据看板」选项

**看板内容：**

| 统计项 | 展示方式 | 说明 |
|--------|----------|------|
| 文物总数 | 数字卡片 | 平台收录文物总量 |
| 类型分布 | 饼图 | 各类型文物占比 |
| 朝代分布 | 柱状图 | 各朝代文物数量 |
| 博物馆排名 | 排行榜 | 按馆藏量排序 |
| 材质分布 | 环形图 | 不同材质占比 |
| 年度趋势 | 折线图 | 数据增长趋势 |

## 5. 用户个人中心

### 5.1 用户注册与登录

**注册流程：**
1. 点击页面右上角「注册」按钮
2. 填写注册信息：
   - 用户名（唯一）
   - 密码
3. 点击「注册」完成

**登录流程：**
1. 点击页面右上角「登录」按钮
2. 输入用户名（用户ID）和密码
3. 点击「登录」按钮
4. 登录成功后自动跳转至首页

**演示账号：**
- 用户名：1001
- 密码：123456


### 5.2 收藏功能

**收藏文物：**
1. 在文物详情页点击「收藏」按钮
2. 或在浏览列表中点击收藏图标

**收藏夹管理：**
1. 进入个人中心「我的收藏」
2. 支持删除收藏

### 5.3 评论与互动（选做）

**发表评论：**
1. 在文物详情页找到评论区
2. 输入评论内容
3. 点击「发表」按钮


## 6. 常见问题

### 6.1 浏览相关

| 问题 | 解答 |
|------|------|
| 如何快速找到感兴趣的文物？ | 使用首页搜索框或高级搜索功能 |
| 图片无法正常显示怎么办？ | 检查网络连接，刷新页面重试 |
| 如何查看文物的详细信息？ | 点击文物卡片进入详情页 |

### 6.2 查询相关

| 问题 | 解答 |
|------|------|
| 搜索结果为空怎么办？ | 尝试使用更宽泛的关键词，或调整筛选条件 |
| 如何导出查询结果？ | 在搜索结果页点击「导出」按钮 |
| 高级搜索支持哪些筛选条件？ | 支持类型、年代范围、材质、收藏地、博物馆 |

### 6.3 可视化相关

| 问题 | 解答 |
|------|------|
| 知识图谱加载缓慢怎么办？ | 尝试调整节点数量限制 |
| 地图无法显示怎么办？ | 检查网络，确保地图资源可访问 |
| 时间轴如何筛选特定朝代？ | 点击朝代标签或使用筛选功能 |

### 6.4 用户中心相关

| 问题 | 解答 |
|------|------|
| 忘记密码怎么办？ | 联系系统管理员重置密码 |
| 如何修改个人信息？ | 进入个人中心点击「修改资料」 |
| 收藏的文物在哪里查看？ | 个人中心「我的收藏」 |
