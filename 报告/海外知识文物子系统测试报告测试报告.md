# 一、测试概述
## 1.1 测试目标
验证海外文物知识服务子系统各功能模块的正确性、稳定性与用户体验，确保：
• 数据查询：模糊查询、多条件组合查询、分类查询、排序查询、文物详情查询
• 用户管理：注册、登录、信息修改、JWT 认证
• 交互功能：收藏（添加/删除/列表）、评论（发表/删除/多维度查询）
• 可视化：知识图谱、时间轴、地理分布图、统计分析看板
• 部署运维：Nginx 反代、前后端联调、Neo4j 远程连接、兼容性

# 八、测试结论
海外文物知识服务子系统经过 v1.0 初始测试与三轮版本维护（5.28 / 5.30-5.31 / 6.1），累计发现并修复 29 个缺陷，当前所有已知缺陷均已关闭。单元测试 28 个用例全部通过（100%），Neo4j 集成以 6 项 curl 验证补充覆盖，可视化 4 模块接口正常。

系统已实现完整的前后端混合架构：Vue 3 前端经 Nginx 反代至 Spring Boot (:8085)，业务数据存储于本地 MySQL，文物数据通过远程 Neo4j (39.106.231.119:7687) 查询。搜索、分类、详情、收藏、评论全链路打通，知识图谱/时间轴/地理分布/统计看板均能正确展示远程数据。

仍有 3 项低优先级待办（Neo4j 单元测试补全、搜索分页、数据源统一），不影响核心功能交付，可在后续迭代中逐步完善。
